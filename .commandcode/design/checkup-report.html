Critical Issues

1. No keyboard navigation path

No visible focus indicators. Keyboard users can Tab but can't tell where they are.

→ Add focus-visible rings to all interactive elements

2. Text contrast failures

text-tertiary (#636366) on surface-elevated (#1c1c1e) is ~2.1:1 contrast — fails WCAG AA.

→ Lighten text-tertiary to at least #98989e (4.5:1)

3. Donut chart invisible to screen readers

SVG has no title, role, or aria-label. Screen reader gets nothing.

→ Add role="img" and a descriptive title element

4. No motion respect

All animations bypass prefers-reduced-motion. No reduced-motion alternative.

→ Add @media (prefers-reduced-motion: reduce)

5. Icon accessibility

Icon-only buttons (close, trash, arrows) lack aria-labels.

→ Add aria-label to every icon-only button

6. Zoom disabled

user-scalable=no and maximum-scale=1.0 block pinch-to-zoom.

→ Remove both restrictions

Watch Items

Browser prompt() for budget

Functional but breaks the dark design aesthetic. Replace with inline edit or bottom sheet.

Delete has no undo

A 3-second toast with "Undo" would be safer than immediate delete.

Small text sizes

text-[10px] and text-[11px] are below Apple HIG minimum of 11pt.

Prescriptions (Ordered)

1. Add focus-visible rings to all interactive elements
2. Lighten text-tertiary to meet WCAG AA (4.5:1)
3. Add aria-labels to all icon-only buttons
4. Add accessible name to donut chart SVG
5. Respect prefers-reduced-motion
6. Remove user-scalable=no from viewport meta
